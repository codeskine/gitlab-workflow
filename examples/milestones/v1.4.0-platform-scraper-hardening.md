## Objective

Harden the platform-scraper against the findings of the `go-audit-2026-06-01` review. The release
groups the concurrency, error-handling, performance, security, and observability work into a single
time-boxed goal so that progress across the five audit epics is tracked in one place. It benefits
the on-call operators (clearer failure signals, safe shutdown) and the maintainers (test coverage,
documented architecture decisions).

---

## Deliverables

- [ ] Concurrency safety — signal-safe shutdown lifecycle, no goroutine leaks, idempotent `Shutdown`
- [ ] Error-handling consistency — fatal startup on tracer/timezone failure, publish errors propagated via `errors.Join`
- [ ] Performance — shared HTTP client with TCP pool and retry, pre-compiled regex filters
- [ ] Security — TLS 1.2 minimum on outbound HTTP, no secrets in error logs, tagged dependencies
- [ ] Observability & testing — unit coverage for `scraper`/`k8s`/`oc`/`config`, health endpoints, Prometheus metrics
